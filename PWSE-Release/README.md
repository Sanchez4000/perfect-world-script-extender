# PWSE Release

Готовые к установке сборки PWSE. Каждая версия размещается в отдельном каталоге.

## Версионирование

Формат: `МАЖОР.МИНОР.ПАТЧ` (semver).

- ПАТЧ — исправление или микроулучшение (`1.0.0 → 1.0.1`).
- МИНОР — новая функциональность без несовместимых изменений (`1.0.1 → 1.1.0`).
- МАЖОР — несовместимое или крупное изменение (`1.x → 2.0.0`).

## Состав версии

```
<версия>/
  gs               Обёртка-стартер; задаёт LD_PRELOAD = pwse_loader.so.
  pwse_loader.so   Загрузчик плагинов.
  plugins/
    _addresses.ini  Библиотека адресов.
    *.so           Плагины.
```

Ядро сервера (`gs.real`) в состав релиза не входит и находится на целевой машине.

## Установка (каталог gamed)

1. При первой установке переименовать исполняемый файл сервера `gs` в `gs.real`.
2. Скопировать содержимое каталога версии в `gamed/`: обёртку `gs`,
   `pwse_loader.so` и каталог `plugins/`.
3. Перезапустить карты (через `start.sh` или из административной панели).

После установки добавление плагина выполняется размещением его `.so` в
`gamed/plugins/` с последующим перезапуском карты.

## Обновление

- Загрузчик: заменить `pwse_loader.so`.
- Плагин: заменить соответствующий `.so` в `plugins/`.
- Адреса: дополнить `plugins/_addresses.ini`.

## Откат

Переименовать `gs.real` обратно в `gs`, удалить `pwse_loader.so` и каталог
`plugins/`. Ядро сервера при установке не изменяется.

## Сборка артефактов

- `pwse_loader.so`: `PWSE-Source/build.bat` (вывод в `PWSE-Source/build/`).
- Плагины: копия `PWSE-SDK` и её `build.bat` (вывод в `build/<имя>.so`).
