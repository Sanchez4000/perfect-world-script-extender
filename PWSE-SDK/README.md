# PWSE SDK

Шаблон проекта для разработки плагина PWSE. Копируется целиком; имя копии
определяет имя выходной библиотеки.

## Требования

- Docker Desktop.

Компилятор и 32-битные библиотеки предоставляются образом сборки; установка
инструментов на хост не требуется.

## Состав

```
include/pwse.h        Контракт плагина (ABI). Подключается плагином.
src/plugin.c          Исходный код плагина.
toolchain/Dockerfile  Образ сборки (Ubuntu 22.04, i386).
build.bat             Сборка: src/*.c -> build/<имя_папки>.so.
reference/_addresses.ini  Справочник доступных функций движка (в сборке не участвует).
```

## Сборка плагина

1. Скопировать папку SDK, задать имя копии равным имени плагина (например,
   `DungeonReset`). Имя папки используется как имя результирующей `.so`.
2. Реализовать логику в `src/plugin.c`.
3. Выполнить `build.bat`. Результат: `build/<имя_папки>.so`.
4. Поместить `.so` в каталог `plugins/` сервера и перезапустить карту.

Первый запуск `build.bat` собирает образ сборки; последующие используют кэш.

## Контракт плагина

- Плагин подключает только `pwse.h` и не линкуется с загрузчиком.
- Точка входа: `int PwsePluginLoad(const PwseApi* api)`. Возврат 0 — успех.
- Доступ к движку — через `api`:
  - `api->Resolve(name)` возвращает абсолютный адрес по имени из библиотеки
    адресов (0 при отсутствии). Результат приводится к типу указателя на функцию.
  - `api->Hook(name, detour, &original)` устанавливает перехват функции по имени.
    В `original` записывается указатель для вызова оригинала.
  - `api->Log(msg)` выводит строку в лог процесса карты.

Детур — обычная функция с сигнатурой, совпадающей с оригиналом. Низкоуровневая
установка перехвата (патч, трамплин) выполняется загрузчиком. Вызов оригинала
производится через указатель `original`.

## Библиотека адресов

Плагин ссылается на функции движка по именам, а не по числовым адресам.
Соответствие «имя → адрес» задаётся файлом `_addresses.ini`, который на сервере
располагается в `plugins/_addresses.ini` и читается загрузчиком при старте.

`reference/_addresses.ini` в составе SDK — справочная копия для разработки.
Если плагину требуется функция, отсутствующая в серверной библиотеке, строку с
её именем и адресом следует добавить в `plugins/_addresses.ini` на сервере.

Отсутствие или неполнота `_addresses.ini` не приводят к сбою: не найденное имя
даёт `Resolve == 0`, а `Hook` возвращает ошибку.
