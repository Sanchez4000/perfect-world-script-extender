# PWSE

Загрузчик плагинов для игрового сервера Perfect World (бинарник `gs`),
по принципу SKSE. Подключается через `LD_PRELOAD`, позволяет добавлять
серверные фичи отдельными плагинами, не изменяя сам бинарник сервера.

## Как работает

1. Обёртка `gs` задаёт `LD_PRELOAD = pwse_loader.so` и запускает настоящее
   ядро сервера (`gs.real`).
2. Загрузчик при старте читает библиотеку адресов (`plugins/_addresses.ini`),
   сканирует `plugins/` и для каждого `.so` вызывает точку входа `PwsePluginLoad`.
3. Плагин ставит хуки на функции движка по именам из библиотеки адресов и/или
   вызывает их напрямую.

Бинарник сервера (`gs.real`) не модифицируется. Адреса функций заданы внешним
файлом и специфичны для конкретной сборки сервера.

## Структура

- `PWSE-Source/` — исходники загрузчика (→ `pwse_loader.so`); `vendor/subhook`.
- `PWSE-SDK/` — шаблон проекта плагина.
- `PWSE-Release/` — готовые к установке сборки по версиям.

## Требования

- Docker Desktop. Сборка выполняется в контейнере; целевая платформа — Linux i386.
  Устанавливать компилятор на хост не нужно.

## Сборка загрузчика

`PWSE-Source/build.bat` → `PWSE-Source/build/pwse_loader.so`.

## Разработка плагина

Скопировать `PWSE-SDK`, задать имя копии, реализовать `src/plugin.c`, собрать
`build.bat` → `build/<имя>.so`. Подробнее — `PWSE-SDK/README.md`.

## Установка на сервер

См. `PWSE-Release/README.md`. Кратко: переименовать `gs` в `gs.real`, скопировать
файлы версии в каталог `gamed/`, плагины — в `gamed/plugins/`.
